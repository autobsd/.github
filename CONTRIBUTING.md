# Contributing to AutoBSD

Thank you for your interest in AutoBSD! We welcome contributions from anyone, whether you are fixing a typo, rewriting a core module, or improving documentation.

By participating in this project, you agree to abide by our codebase standards and licensing terms.

---

## Licensing & Copyright Policy

All projects under the AutoBSD organization are licensed under the **BSD 2-Clause "Simplified" License**. 

### 1. Inbound == Outbound
By submitting a Pull Request to any AutoBSD repository, you explicitly agree that your contributions will be licensed under the project's existing BSD 2-Clause terms.

### 2. File Headers & Attribution
To keep source code files readable and maintainable, AutoBSD uses a unified copyright header. Individual authors are not listed inside the file headers. Instead, all individual copyrights are bundled into an umbrella placeholder, and explicit authorship is tracked via Git history.
